# Magical Development

Magic can propel development in some fields while leaving others crude, expensive, or neglected. Its presence does not establish a single technological level: each useful application depends on available mana, materials, instruments, trained operators, maintenance, safety, and institutions capable of coordinating them.

## Useful Questions

- Which task does magic perform more cheaply or reliably than a mundane method?
- Which input or process ( mana, reagents, precision workmanship, training, fuel, transport, records, or maintenance ) becomes the new bottleneck?
- Does a magical solution centralise work in a specialist institution or distribute it among households?
- Which mundane technique has advanced because magic improves measurement, materials, safety, or power?
- Which mundane technique has stagnated because magic supplies an adequate but limited substitute?

For the first settlement, decide only the capabilities visible in daily life: water, heat, light, food, construction, sanitation, transport, communication, measurement, records, and local safety. The answer should make the place useful and recognisable without making it technologically uniform or effortlessly convenient.
