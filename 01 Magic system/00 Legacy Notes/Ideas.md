
# Spell Classification

Instead of classifying spells only by effect, classify them along several technical axes.

## By execution mode

|Class|Meaning|
|---|---|
|**Wild**|Biological, non-symbolic|
|**Reflexive**|Memorized mental construct|
|**Structured**|Actively assembled construct|
|**Instrumental**|External physical construct|

## By construct persistence

|Class|Meaning|
|---|---|
|**Transient**|Exists only during casting|
|**Held**|Maintained consciously|
|**Latent**|Dormant until triggered|
|**Persistent**|Continues without active caster|
|**Cyclic**|Repeats until depleted or stopped|
|**Self-regulating**|Observes conditions and adjusts behavior|

## By targeting model

|Class|Meaning|
|---|---|
|**Contact**|Requires touch|
|**Line-of-sight**|Requires visual or directional access|
|**Bounded area**|Affects a defined region|
|**Anchored**|Bound to object/place/person|
|**Resonant**|Targets via link, signature, or attunement|
|**Semantic**|Targets by identity/classification; usually Ontic-adjacent|

## By operational composition

|Class|Meaning|
|---|---|
|**Simplex**|One declension|
|**Duplex**|Two declensions|
|**Composite**|Three or more declensions|
|**Coupled**|Declensions affect each other directly|
|**Sequential**|Declensions execute in order|
|**Concurrent**|Declensions execute simultaneously|
|**Recursive**|Output modifies future spell behavior|

## By safety profile

| Class             | Meaning                            |
| ----------------- | ---------------------------------- |
| **Constrained**   | Strong built-in limits             |
| **Open**          | Allows wide parameters             |
| **Volatile**      | Sensitive to disruption            |
| **Runaway-prone** | Can self-amplify                   |
| **Contaminating** | Leaves undesired mana around       |
| **Backlashing**   | Failure feeds into caster/operator |
