# Magic System Guide

**Type: Navigation**

**Status: Active**

**Scope: Ordered development stubs for the replacement magic system**

The replacement system is organized into narrow topic stubs under `01 Key Concepts`. Each retains brainstormed foundations, tentative ideas, or open questions at their existing approval scope. These are preparation for detailed documentation. The previous system remains in [[99 Workshop/Previous Magic System Archive|the complete archive]].

## Reference Preparation

Select terminology, then convert the in-file notes into detailed documentation comparable in depth and organization to the previous magic-system references. Begin with the base mana system and form relationships, then prioritize conceptual manipulation and execution. Develop access, autonomy, training, and shared practice as their prerequisites become available. The numbering provides a reading order rather than requiring every question to be settled before a narrow topic can be developed.

Keep working vocabulary with its mechanism. [[10 Magic System/01 Key Concepts/01 Core Principles|Core Principles]] retains terminology-review notes; [[00 Core/04 Terminology|Terminology]] is available for shared definitions when selected. Additional terminology suggestions and unresolved mechanics require author approval at their actual scope.
