## Primitive Declensions

| Scientific Name | Common Names                                 | Operation Domain                                                                            |
| --------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Locative**    | Position, Translation, Teleportation         | Change an object's position in space.                                                       |
| **Kinetic**     | Motion, Force, Heat                          | Change the momentum distribution of matter (uniform or microscopic).                        |
| **Massic**      | Mass, Weight, Gravity                        | Modify an object's inertial and gravitational mass.                                         |
| **Volumic**     | Pressure, Density, Compression, Expansion    | Change local volume and spacing between matter while preserving mass.                       |
| **Radiant**     | Light, Illusion, Cloaking                    | Emit, absorb, redirect or otherwise manipulate photons.                                     |
| **Galvanic**    | Lightning, Magnetism                         | Modify electric charge and charge distribution.                                             |
| **Temporal**    | Acceleration, Preservation, Stasis           | Modify the local rate at which time progresses.                                             |
| **Resonant**    | Linking, Attunement, Observation, Divination | Establish, strengthen or weaken persistent interactions between otherwise separate systems. |
| **Cohesive**    | Structure, Shaping, Binding                  | Alter adjacency and continuity relationships within matter.                                 |
| **Mnemonic**    | Memory, Recording, Engraving                 | Encode, erase or modify information stored in physical systems.                             |
| **Ontic**       | Identity, Essence, Classification, Soul      | Modify what an object fundamentally _is_ according to magical law.                          |
