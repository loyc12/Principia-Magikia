# Core Premise

| Aspect         | Summary                                                                                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Genre          | Hard fantasy with light isekai elements                                                                                                                              |
| Core Concept   | A modern programmer/engineer is stranded in a fantasy world where magic is a deterministic natural phenomenon that has never undergone a true scientific revolution. |
| Central Hook   | Magic is treated like physics rather than mysticism. The protagonist introduces the scientific method, not modern technology itself.                                 |
| Tone           | Grounded, optimistic, exploratory, occasionally humorous, character-driven.                                                                                          |
| Long-term Goal | Transform magic from an empirical craft into an organized science while gradually finding a place to belong in the world.                                            |
